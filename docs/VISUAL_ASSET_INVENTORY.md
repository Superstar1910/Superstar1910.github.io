## Intake policy

1. No candidate image is automatically public.
2. Verify original image, creator/source, related project, copyright, confidentiality, numerical accuracy and approved caption.
3. Keep original provenance and avoid false claims that illustrative imagery depicts a named project.
4. Optimise approved images for web; strip sensitive EXIF/location metadata.
5. Publish through reviewed pull requests; maintain a manifest with id, title, category, original source, rights, approval and website path.
6. Keep private or unreviewed images outside the public GitHub repository.
